⚡ Quick Tips for Your Setup
  • ✦ For Theatre projects, be sure to use only the 1st show date as the project date; all other show dates get added as additional events to the same project + start their own workflows
  • ✦ Theatre and Event projects both lead to the ~Theatre/Events Gallery Delivered workflow at the end
  • ✦ To add a client's gallery link to their project (and for automated emails), click the small pencil button on the right side of the project screen to edit, then find the field for the link and paste it in
  • ✦ Watch for the to-do's that indicate an email will send after completion; these emails automatically go after you check it complete
