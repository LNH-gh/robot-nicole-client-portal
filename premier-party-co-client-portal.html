  • 2Questionnaire sent to client when availability confirmed
  • 3Follow-ups workflow starts automatically after questionnaire is sent

▾

Quote, calendar update upon 1st invoice payment, event confirmation, starts Fulfillment workflow.

  • 1Quote/contract/invoice sent
  • 2Calendar updates automatically upon first payment
  • 3Thanks for booking email sends automatically after calendar update
  • 4Fulfillment workflow starts automatically after booking confirmation
  • 5Reminder to add takedown time to calendar if relevant
3 - Event Decor Fulfillment 8 stages
▾

Tagging for pipeline movement, event reminder email, thank you email, initiates Rebooking workflow.

  • 1Tag moves client across pipeline 30 days before event
  • 2Tag moves client across pipeline 7 days before event
  • 3Event reminder email sends automatically 7 days before the event
  • 4Reminder to send text template 2 days before the event
  • 5Tag moves client across pipeline 1 day after event
  • 6Thank you & Google review email cues up 2 days after event
  • 7Reminder to use [INTERNAL] Rebooking form to set up repeat workflow
  • 8Automated archive
